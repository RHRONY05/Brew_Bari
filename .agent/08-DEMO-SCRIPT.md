# 08 — Demo script (≈ 5 minutes)

The finished product must support this pitch exactly. Agents: use it as the final acceptance test (T7.5).

**Setup:** salesperson's laptop (or tablet) shows the **Counter board** logged in as admin, "Start shift" pressed, sound on. Printed table QR card (Table 1) on the owner's table. Package set to **P3**. Phone charged, on 4G.

## 1. The problem (30 s)
"Your menu is a heavy book, prices change, items run out, and guests wave for a waiter. Let me show you the alternative."

## 2. Package 1 — Digital menu (60 s)
1. Hand the owner the printed QR → they scan with **their own phone** → Brew Bari menu opens instantly, no app.
2. Scroll: offer banner (Mango season), categories, photos. Tap **Caramel Macchiato** → options, price changes with Large.
3. Tap **Quick** → only drinks and bites ready in 5 minutes or less. "Guests in a hurry pick these, and every item shows roughly how long it takes."
4. Tap **বাং** → whole menu in Bangla with ৳ in Bangla numerals.
5. Info button → Wi-Fi password copy. "Guests stop asking for the Wi-Fi."
6. On the laptop: **Admin → Menu** → toggle **Mocha** sold out → on the phone, reload: Mocha greyed out and moved to the end of Hot Coffee. "You control it in seconds — no reprinting."

## 3. Package 2 — Call Waiter (60 s)
1. Admin → Settings → Package **P2**.
2. Phone: add Cappuccino ×2 to the list → **Call waiter with this list**.
3. Laptop **chimes**: "Table 1 — Calling" card with the list and total. "Your waiter walks over already knowing the order. Fewer waiters can handle more tables."
4. Tap **Waiter sent** → phone shows "Waiter coming".

## 4. Package 3 — Premium (90 s)
1. Settings → **P3**.
2. Phone: add Iced Latte + Brownie → **Place order**.
3. Laptop: Accept → Preparing → Ready → Served; the phone's order tracker moves along.
4. Phone: **View bill** (with VAT) → **Request bill** → laptop shows Bill card.
5. Phone: rate ★★★★★, write "Great coffee!" → **Review us on Google** → Google review page opens with the comment ready to paste. "More Google reviews every day, without asking."
6. Laptop: **Paid & close table** → the table is ready for the next guests.

## 5. Close (30 s)
Show the **Tables & QR** print sheet and the three package cards in Settings. "We set this up with your menu and photos, print the QR cards, and train your staff in one visit."

## If something goes wrong
- Phone has no internet → use the salesperson's phone on a hotspot.
- Counter didn't chime → the browser blocked audio: press **Start shift** again.
- Need a fresh table → Counter → Table 1 → **Close table**, rescan.
